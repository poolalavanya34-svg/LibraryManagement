# 📚 Simple Library Record Manager

A feature-rich desktop application built for college project submissions to manage library inventories, book issuance, student returns, overdue fines, and real-time analytics.

## 🚀 Tech Stack
* **Language:** Python 3.x
* **GUI Framework:** Tkinter (Built-in)
* **Database:** SQLite (`library.db`)

## ✨ Core Features
* **Dashboard Analytics:** Real-time statistics on total book titles, stock capacity, active loans, and low-stock alerts.
* **Book Management:** Add, update, delete, search, sort (A-Z), and filter books by category with CSV export support.
* **Issue & Return Tracking:** Manage student book borrowing with automated stock validation.
* **Overdue Fine Calculation:** Automatically computes fines (₹10/day) for late returns.
* **Audit Trail & Activity Log:** Complete history log of all library transactions.
* **Dark/Light Mode:** Instant theme switcher for user interface comfort.
